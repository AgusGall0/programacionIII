OPERACIONES CON EL ORM (python manage.py shell)

1. Crear y guardar al menos tres actividades deportivas

>>> from reservas.models import ActividadDeportiva, Horario, Inscripcion
>>> from datetime import time
>>> futbol = ActividadDeportiva(nombre='Fútbol 5', descripcion='Partidos de fútbol en cancha reducida.', lugar='Cancha sintética del Campus', cupo=10)
>>> futbol.save()
>>> voley = ActividadDeportiva.objects.create(nombre='Vóley', descripcion='Entrenamiento y partidos de vóley mixto.', lugar='Gimnasio Universitario', cupo=12)
>>> natacion = ActividadDeportiva.objects.create(nombre='Natación', descripcion='Clases de natación para todos los niveles.', lugar='Natatorio Municipal', cupo=15)
>>> ActividadDeportiva.objects.count()
3

2. Crear y guardar al menos dos horarios para una de las actividades deportivas

>>> h1 = Horario(actividad=futbol, dia=Horario.Dia.LUNES, hora_inicio=time(18, 0), hora_fin=time(19, 30))
>>> h1.save()
>>> h2 = Horario.objects.create(actividad=futbol, dia=Horario.Dia.MIERCOLES, hora_inicio=time(20, 0), hora_fin=time(21, 30))
>>> h3 = Horario.objects.create(actividad=voley, dia=Horario.Dia.JUEVES, hora_inicio=time(17, 0), hora_fin=time(18, 30))
>>> Horario.objects.count()
3

3. Crear y guardar al menos tres inscripciones asociadas a los horarios disponibles

>>> i1 = Inscripcion(nombre='Juan', apellido='Pérez', dni='40123456', horario=h1)
>>> i1.full_clean()
>>> i1.save()
>>> i2 = Inscripcion.objects.create(nombre='María', apellido='Gómez', dni='41234567', horario=h1)
>>> i3 = Inscripcion.objects.create(nombre='Lucas', apellido='Díaz', dni='39876543', horario=h2)
>>> i4 = Inscripcion.objects.create(nombre='Sofía', apellido='Romero', dni='42345678', horario=h3)
>>> Inscripcion.objects.count()
4

8. Modificar el cupo de una actividad deportiva

>>> voley = ActividadDeportiva.objects.get(nombre='Vóley')
>>> voley.cupo
12
>>> voley.cupo = 16
>>> voley.save()
>>> ActividadDeportiva.objects.get(nombre='Vóley').cupo
16
>>> ActividadDeportiva.objects.filter(nombre='Natación').update(cupo=20)
1
>>> ActividadDeportiva.objects.get(nombre='Natación').cupo
20

9. Cambiar el estado de una inscripción de Activa a Cancelada

>>> inscripcion = Inscripcion.objects.get(dni='41234567', horario=horario)

>>> inscripcion.estado = Inscripcion.Estado.CANCELADA
>>> inscripcion.save()
